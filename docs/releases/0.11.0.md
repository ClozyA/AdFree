# AdFree 0.11.0

- 使用 Miuix TabRow 将界面分为「首页」与「设置」：首页展示连接概览、适配应用和作用域管理，设置页集中提供日志、更新与诊断工具。
- 新增检查更新，仅查询 GitHub 最新正式版；发现新版本后可前往对应 Release 页面下载，支持网络失败和请求受限提示。
- 新增「保存日志」开关，默认开启，保存 AdFree 运行日志与模块在目标应用中输出的 Hook 日志。最多保留 3 个 512 KiB 文件，自动轮转；关闭后停止保存新日志，已有日志仍可导出。
- 新增「导出日志」，通过系统文件选择器保存包含环境信息的 UTF-8 文本，无需存储权限。

适配应用：小步点 2.6.8、5E 对战平台 7.2.5。广告拦截规则逻辑保持不变，原有 LSPosed 日志继续输出。

升级后请完全退出并重启目标应用，以加载日志收集代码并记录完整启动过程。日志队列满或跨进程写入失败时可能丢弃条目；手机上的界面、更新请求、跨进程日志收集和文件导出仍需真机验证。

提供 Release、Debug 和 SHA-256 校验文件，推荐使用 Release。沿用项目发布证书，可覆盖安装此前使用同一证书的版本。
