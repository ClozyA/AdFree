# AdFree 0.8.0

- 使用 Compose + Miuix 的模块工作台，支持系统深浅色。
- 连接概览、适配应用和环境信息工具使用独立区块。
- 包名更新为 `xyz.fearr.adfree`。
- 沿用小步点 2.6.8、5E 对战平台 7.2.5 的现有适配规则。
- 提供固定签名的 Release 和 Debug APK，以及 SHA-256 校验文件。

推荐安装 Release；Debug 用于问题排查。两种构建使用同一发布证书，可相互覆盖安装。

从旧包名迁移时，请在 LSPosed 中停用旧模块，再启用新版并重新选择作用域。此前本地 Debug 包使用 Android 默认调试证书，与本次发布证书不同；如安装提示签名冲突，需要卸载此前的同包名调试版后再安装。

此版本拦截包含激励广告，不保留奖励流程。适配仅针对上述版本，其他版本会跳过规则。小步点已获用户页面反馈；5E 新增强制规则仍待真机验证。框架服务连接不等于目标应用注入成功。
