# AdFree 0.9.0

- 使用 Miuix Badge：LSPosed 连接正常显示绿色，未连接显示红色。
- 更新绿色几何 A 图标，提供自适应和单色主题图标。
- 读取当前用户下适配应用的安装状态、版本名及版本号；未安装时显示提示。
- 版本不匹配时提示并继续尝试注入，不再通过版本号停用规则；无法定位的类或方法跳过对应规则。
- 应用内的 Miuix Switch 可申请加入或移除真实框架作用域。加入可能需要 LSPosed 授权，开关以框架返回结果为准。
- 作用域变化后需完全退出并重启目标应用，已运行进程中的 Hook 不会即时撤销。

保留 0.8.0 的发布证书，可覆盖安装。提供 Release、Debug 和 SHA-256 校验文件，推荐日常使用 Release。

用户已反馈两款应用的现有适配正常。本轮新增界面、版本提示和作用域授权交互交由用户真机验证；单元测试覆盖授权拒绝、移除失败、断线和过期回调等路径。
