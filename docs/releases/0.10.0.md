# AdFree 0.10.0

- 精简界面文案，移除常驻说明、宣传语、重复页脚及遗留的字符串资源和空白间距。
- LSPosed 连接概览整张卡片使用状态配色：已连接绿色，未连接红色，并适配深色主题。
- 更新自适应应用图标及单色主题图标。
- 显示两款适配应用的实际安装版本，提示未安装或版本不匹配；版本不匹配仍继续尝试注入。
- 应用内可申请加入或移除 LSPosed 作用域，开关显示框架实际结果。

适配应用：小步点 2.6.8、5E 对战平台 7.2.5。现有广告拦截规则保持不变，包含激励广告，不保留奖励流程。

加入作用域可能需要 LSPosed 授权。修改后需完全关闭并重启目标应用，已运行进程中的 Hook 不会立即撤销。

提供 Release、Debug 和 SHA-256 校验文件，推荐使用 Release。沿用项目发布证书，可覆盖安装此前使用同一证书的版本。
